# HARBOR HOPS 🍺
### 横浜 生クラフトビール完全ガイド

横浜・大さん橋を起点に、徒歩圏内で生クラフトビールが飲める専門店を集めたガイドページです。

## 収録エリア・店舗数

全31店舗 / 6エリア

| エリア | 特徴 |
|---|---|
| 大さん橋付近 | 徒歩15分圏内 |
| みなとみらい・新港 | 港エリアのブルーパブ |
| 関内・馬車道 | クラフトビールの激戦区 |
| 野毛・桜木町 | 個性派バーが集まる下町 |
| 日ノ出町・伊勢佐木 | 大岡川沿いの隠れ家系 |
| 横浜駅周辺 | 電車利用推奨の名店 |

## 主な機能

- Leafletマップで全店舗の位置を確認
- エリア別スティッキーナビゲーション
- 店舗カードのアコーディオン（詳細情報）
- モバイルファースト・レスポンシブ対応

## 技術

- シングルファイルHTML（CSS・JS・画像すべてインライン）
- [Leaflet.js](https://leafletjs.com/) + CartoDB Dark Matter
- Google Fonts（Oswald / Barlow）

## 注意事項

掲載情報（営業時間・定休日・価格）は変更される場合があります。  
訪問前に各店舗の公式サイト・SNSでご確認ください。
